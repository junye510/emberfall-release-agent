# Emberfall

Twin-stick survival in the ash. Keep the camp ember lit, aim with the other stick, and extract before the night wave closes.

## [0.4.0] - 2026-10-18 — Cinder Orchard

### Added
- Cinder Orchard biome: wind-driven ember gusts, burning root mazes, and the Orchard Heart elite at the grove center.
- Heat-sink relics. They shorten dodge distance and slow ember decay, so a greedy build can outlast a long wave.
- Couch guest tether. A second controller joins the same run without its own save file.

### Changed
- A perfect dodge now pauses ember decay for 1.5 seconds instead of refilling the whole gauge.
- Extraction flares spawn at the map edge. They no longer drop on the player's feet at wave clear.

### Fixed
- Controller aim no longer snaps back to the last mouse position after alt-tab (BUG-091).
- Unpausing during a wave no longer eats the first shot (BUG-102).
- The result screen shows the seed that was actually played (BUG-077).

### Known issues
- Orchard Heart's root slam can wipe a run when the ember gauge is already empty.
- The couch guest does not receive boss subtitles.
